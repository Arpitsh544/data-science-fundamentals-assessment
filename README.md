# Data Science Fundamentals Assessment

Task 1 of the Data Science internship program. This repository contains a
self-contained Jupyter notebook covering the Data Science lifecycle, Python
programming basics, statistical foundations, data types & structures, and a
set of practical assignments.

## Contents

- `Data_Science_Fundamentals_Assessment.ipynb` — main notebook (fully executed,
  outputs included)
- `data/students_sample.csv` — small sample dataset used for the data-types
  and statistics sections
- `requirements.txt` — Python dependencies

## Topics covered

1. Data Science lifecycle, types of analysis, and industry use cases
2. Python basics — variables, operators, conditionals, loops, functions,
   lists, tuples, dictionaries, sets, file handling
3. Statistical foundations — mean, median, mode, variance, standard
   deviation, percentiles, probability, correlation
4. Data types & structures — numerical, categorical, ordinal, datetime, text
5. Clean-coding and reproducibility practices
6. Practical assignments (sum/average/product, average of a list, variable
   swap, loops, odd-position digits, binary search, string concatenation,
   smallest of three, text statistics)

## How to run

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
jupyter notebook Data_Science_Fundamentals_Assessment.ipynb
```
